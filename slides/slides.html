La notation · bench/score.py
def noter_reponse(question, reponse):
    texte = reponse.lower()
    points = sum(1 for c in question["criteres"]
                 if any(m.lower() in texte for m in c))
    return points / len(question["criteres"])

Des mots-clés obligatoires. Puis une relecture humaine.

{{CHROME}}
Le protocole est écrit comme une suite de tests. Chaque question a des critères ; chaque critère accepte plusieurs mots. C'est simple, donc ça se trompe parfois : on le verra, et c'est pour ça qu'un humain relit chaque note.
Ce qu'on mesure
  • Bonnes réponses · notation automatique + relecture

  • Temps · 3 passages, session neuve à chaque question
